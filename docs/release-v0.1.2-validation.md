# v0.1.2 发布验证

本版为 macOS arm64 的实验版 CLI 分发，提供对应源码和依赖源码。验证关注项目读改写闭环、发行包独立运行及发布数据边界；完整 GUI 对等保持独立验收。

## 已完成的源代码验证

- 原生项目接口、结构化代码、事务、SDK、项目 I/O、旧配方、安全检查及 reporter 身份回归：74/74 通过。测试 SB3 在临时目录中合成，不依赖公开二进制项目夹具。
- 原项目编辑升级全套串行回归：357/357 通过。此前并发运行中有一次录制 RSS 阈值失败；该项单独及随后串行运行通过，原始失败证据保留在本地。此处不宣称并发性能门槛已通过。
- 零尺寸 SVG 和 64 MiB 元数据修复的相关验证：51/51 通过；300 MiB 项目输入边界相关验证：70/70 通过。
- 离线资源完整性：1610 个文件，301 个扩展文件，1304 个素材全部可用，无缺失或校验错误。
- 参数及文档检查：版本为 0.1.2；52 个命令族，无缺失必需文件或无效命令 schema；`git diff --check` 通过。
- 发布包审计工具验证：合法源码 ZIP 被接受，嵌套 ZIP 中的 SB3 被拒绝。

## 独立运行包验证

便携 ZIP 解压到新临时目录，PATH 仅含系统工具，并设置无效的主机 Node 配置作为隔离检查。15 项操作通过：随包 Node 24.18.0 的 doctor、新建项目、旧 demo 配方、read/find/validate/apply、保存后重开、固定种子运行、exec 子进程编辑、PNG 渲染、SDK 包入口及篡改拒绝。

JSON 编辑后角色运行位置为 x=33；JavaScript 编辑后重开运行位置为 x=41。生成的 PNG 为 480×360。原生 WebGL 的动态库路径已改为相对发行包的 loader 路径，核心流程无需源工作区、系统 Node/npm 或 Homebrew。发行环境为 macOS 15.7.7 / arm64。

编译采用 esbuild 0.25.12，保留动态加载所需的冻结上游依赖。每个已编译模块及已安装包的版本／源哈希在 `DEPENDENCY-MANIFEST.json` 中记录；payload 的大小与哈希在 `PORTABLE-MANIFEST.json` 中记录。最终附件的 SHA-256 与递归数据审计结果随 Release 提供。

## 发布数据边界

GitHub 使用独立公开仓库的既有历史。本地父仓库及其历史、现有游戏、训练数据、用户项目、IDE 元数据、原始验证日志不推送。新版公开树删除历史版本的合成 SB3 夹具；旧提交仍属于既有公开历史。

源码文件采用明确清单；ZIP 审计递归检查嵌套 ZIP，禁止 SB/SB2/SB3/Sprite 项目、私有目录、符号链接及未审计压缩格式。上游扩展源码包保留代码、构建脚本与许可，移除官方示例项目，记录原档案哈希及排除条目。本地原档案与现有项目保留。

## 验收边界

`release:check` 的完整对等门禁仍返回 2，`releaseReady:false`。图像／音频差分、跨平台、性能、权限和真实设备验收未全部完成。该结果不用于把实验版描述为完整 GUI 对等版本。

运行包带 Node 24、原生依赖与资源；源码构建仍使用锁定依赖。视频录制所需 FFmpeg/FFprobe 为可选外部工具，不随本包分发。运行文件默认只读并校验完整性，所有者仍可修改或重建软件；JavaScript 编辑脚本具有普通本地 Node 权限。
