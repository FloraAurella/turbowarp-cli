# 当前能力与限制

当前版本为 0.1.0 实验版。以下是现有实现和仍未完成的验收范围。入门操作见 [分步教程](quickstart.md)，逐动作证据见 [交付审计](completion-audit.md)。

## 功能边界

- **项目**：本地 SB/SB2/SB3 导入及 sprite3、恢复点、文件背包已有真实往返测试。Legacy SVG/getBBox 兼容未完整 GUI 对拍。`project fetch` 支持显式 HTTPS 项目 URL；Scratch ID/token 与多资产获取仍未完成。
- **图库**：1304 个冻结素材随 `resources/` 提供，MD5 与 SHA-256 全量校验；运行时不隐式下载。
- **积木**：`blocks` 提供图校验、复制、连接、菜单和过程编辑；基础 `block` 入口仍保留。布局使用确定性语义尺寸，不保证 Blockly 像素一致；并非所有外部 XML 剪贴格式都支持。
- **绘图**：多选、组合、层序、路径点/手柄、渐变、位图选区、取色、剪贴及转换已实现。复杂 SVG 组合、stroke/text 擦除、Paper 填充命中/曲率/画笔和平滑仍有缺口，不属于 D7 豁免。
- **声音**：选区十种冻结 GUI 音效、剪切/复制/粘贴/trim/fade 及原生 WAV 输出已实现。原生数值参照不等浏览器音频差分；实时采集不支持。
- **运行**：`run` 使用帧时钟、seed、watch 与有界 primitive trace；`runtime` 支持持续 start/pause/resume/stop/step、断点、回答和克隆。积木单步/断点/trace 仅解释模式。运行副本克隆最多300，保留更小的项目限制；这是资源边界，不是 D7。
- **设备**：`device` 与旧 `input` 只验证并入预录队列，不向编辑 VM 注入、不改变标准项目或启动编辑脚本。事件在运行副本对应帧执行。真实六类硬件、实机手柄/振动尚未验收；mock 不等真实设备。
- **字体**：7 个冻结字体及自定义字体二进制、SB3 往返和原生字形可用。系统字体命令只保存兼容 metadata，不访问宿主字体库；浏览器 hinting、复杂文字 shaping 和抗锯齿仍待对拍。
- **录制**：离屏 PNG 帧、外部预录 WAV 混音、显式 ffmpeg/ffprobe 的 MP4/WebM 编码已有测试。**全项目音轨录制仍明确拒绝**，默认 `projectaudio=false` 与 GUI 默认不同。项目音轨缺口不能用实时麦克风 limited 掩盖。
- **打包**：简单 `package` 使用同一安全 `pack build` 路径。58 个默认叶选项、8 局部 reset、HTML/ZIP/one-asset 及官方 WebView Mac 封装已有证据。其余目标列出并接下载校验，不代表所有平台下载/播放完成；videoSensing/Gamepad 预录提供器转包仍拒绝。
- **扩展与 addons**：安全执行批准 pen/music 和 CLI 离线 videoSensing/Gamepad；其它可执行扩展仍 fail-closed。81 个 addon 的148设置/13预设可配置，配置成功不代表各插件所有行为已实现。任意未来 DOM 插件不承诺兼容，冻结范围的缺口仍保留。
- **监视器**：状态、范围、列表 CSV/JSON 导入导出已有指令；PNG 尚未绘制监视器面板，不能声称完整视觉对等。

## 编辑历史与自动化

历史是共享的项目事务栈，每栈最多 99 个快照，并受 200 MiB 预算约束；至少保留一个可恢复快照。关闭进程后不会保留历史。角色及资源条目 UUID 保存在 SB3 的 `tw-cli-state.json`；条目身份与内容 MD5 不同，重命名、重排、编辑和重新打开保持身份，复制条目生成新 UUID。

失败编辑或失败的项目输出会回滚编辑状态。外部文件不属于项目事务：导出的剪贴快照不会因 `undo` 删除，本地云状态的写入也不随项目撤销。

JSONL 默认串行处理，单条错误后继续；自动化需要检查每条响应的 `ok`。`--fail-fast` 在首次错误后停止，若仍有未保存修改则退出 2。协议、错误码与节点映射见 [Agent 与脚本指南](agent-usage.md)。

## 安全、权限和文件

- 默认拒绝网络、任意扩展执行和真实设备；每条敏感命令必须使用精确 `--allow`，授权不传给后续命令、父目录或配置内嵌路径。直接指定的输入/输出路径只授权该文件。
- `permission list` 列出权限。打包自定义 JS/CSS 只授权**作为产物内容写入**，不会在 CLI 中执行，也不构成恶意代码沙箱。
- 输入有大小/类型限制，描述符使用 `O_NOFOLLOW`、可用时 `O_NONBLOCK`，分块有界读取；检查叶子及父目录符号链接。macOS `/tmp`、`/var` 仅在指向系统 `/private` 别名时例外。
- 输出独占临时文件、fsync、回读校验，再原子提交；不能用 `--force` 绕过符号链接拒绝。不能保证抵御拥有同一用户权限的攻击进程在所有平台制造的目录竞态；这不是 OS 沙箱。
- 不读取旧 IndexedDB/localStorage 用户数据库。偏好、背包、云和恢复点都需显式文件/目录。
- 真实设备验收、跨平台安装、性能对照与 GUI 图像/音频差分尚未完成。开发期 GUI oracle 也未启动，仍需明确授权；生产路径保持无前端。
